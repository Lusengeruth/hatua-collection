# HATUA COLLECTION 👟

> Boutique de chaussures premium en ligne — Goma, Congo DRC

![Hatua Collection](./public/images/hero-shoe.jpg)

## 🌍 Apercu

**Hatua Collection** est une boutique e-commerce complete specialisee dans la vente de sneakers et chaussures formelles a Goma et partout au Congo DRC.

- **Livraison a Goma**: 24-48h pour seulement 1$
- **Livraison nationale**: 3-7 jours partout au Congo DRC
- **Commande via WhatsApp**: Simple et rapide
- **Paiement**: Cash, Airtel Money, M-Pesa, Orange Money

---

## 🛠️ Stack Technique

### Frontend
- **React 18** + **Vite**
- **React Router v6**
- **CSS-in-JS** (inline styles)
- Google Fonts (Playfair Display + DM Sans)

### Backend
- **Node.js** + **Express.js**
- **MongoDB Atlas** (database)
- **Cloudinary** (stockage images)
- **JWT** (authentification admin)
- **Nodemailer** (notifications email)

---

## 🚀 Installation locale

### Prerequisites
- Node.js 18+
- Compte MongoDB Atlas
- Compte Cloudinary
- Gmail avec App Password

### Frontend
```bash
cd hatua-collection
npm install
npm run dev
# → http://localhost:5173
```

### Backend
```bash
cd hatua-backend
npm install
# Configurez le fichier .env
npm run dev
# → http://localhost:5000
```

### Variables d'environnement (.env)
```env
MONGO_URI=your_mongodb_uri
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
JWT_SECRET=your_jwt_secret
ADMIN_EMAIL=admin@email.com
ADMIN_PASSWORD=your_password
EMAIL_USER=your_gmail@gmail.com
EMAIL_PASS=your_gmail_app_password
```
